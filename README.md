# HALAF TV Launcher

مشروع أولي للانشر Android TV / Android Box.

## البناء عبر GitHub
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد على الفرع `main`.
2. افتح تبويب **Actions** في المستودع.
3. إذا طلب GitHub تفعيل Actions فوافق.
4. شغّل سير العمل **Build HALAF TV Launcher APK** أو ادفع أي تعديل إلى `main`.
5. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل الملف من **Artifacts**.

## ملاحظات
- هذه نسخة تأسيسية وليست الإصدار النهائي.
- تم إعداد معرف التطبيق: `com.halaf.tvlauncher`.
- الواجهة الحالية نموذج أولي للتنقل بالريموت.
- الخلفيات الديناميكية، اكتشاف التطبيقات، الطقس، مكتبة الوسائط ومشغل الفيديو ستضاف تدريجياً.
- لا يحتوي المشروع على محتوى بث تلفزيوني أو قوائم قنوات جاهزة.
